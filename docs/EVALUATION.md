## Method

* **Test sets.** `eval/data/raw/*.json`: synthetic Hungarian texts (e-mails, chat, legal, health, HR, public sector, sales, real estate, finance, IT, education, care, insurance, logistics, hospitality, construction, social services, deliberately hard cases) with entity labels written by AI agents (not by humans), including inflected forms; dev 146 texts / 1098 entities, held-out #1 78 texts / 652 entities, held-out #2 74 texts / 406 entities, held-out #3 74 texts / 457 entities, held-out #4 74 texts / 565 entities. Each held-out set was written before the recognizer changes it tests, by agents that did not see the code; I did not read its texts before the first measurement. Labels verified by a second, independent AI agent; contact data scrubbed (`eval/scrub_raw.py`); identifiers with check digits are filled in from generators at build time (`eval/build_testset.py`).
* **Baselines** (*old code*): the same evaluation run from a git worktree at commit `a055555` (before round 3) with the lexicon of that time.
* **Detection metrics** (`eval/evaluate.py`): *exact* = same span and type; *overlap* = same type, spans overlap; *protected* = ≥95% of the entity's characters covered by any predicted span regardless of type (what matters for privacy). Wilson 95% intervals. Each backend runs in its own process; memory is RSS.
* **Restoration** (`eval/restore_eval.py`): every name is masked in each of the 12 cases of its gold inflection table (persons and companies use different case sets), then a simulated model mentions it again in a random case from the same table with a perturbation real models produce (missing brackets, glued or en-dash endings, lower case, markdown, first-name-only or *X úr* mentions, upper case). The expected text comes from gold inflection tables (`eval/data/inflection_gold*.json`) written by two independent AI annotators (dev: plus an AI adjudicator), never from the engine under test.
* **OCR** (`eval/ocr_eval.py`) and **stack performance** (`eval/perf_stack.py`): see their sections.
* **Not measured:** real LLM behaviour, real documents and scans, human-verified labels, multi-turn conversations, English-language detection quality, Surya OCR and the local LLM.
