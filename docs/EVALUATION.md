## Method

* **Test sets.** `eval/data/raw/*.json`: synthetic Hungarian texts (e-mails, legal, clinic, invoice, everyday and deliberately hard cases) with entity labels written by AI agents (not by humans), including inflected forms. Dev: 146 texts / 1098 entities; held-out #1: 78 / 652 (round 1); held-out #2: 74 / 406, six new domains, written before round 2. Generated by AI agents, labels verified by a second, independent AI agent; contact data scrubbed (`eval/scrub_raw.py`); identifiers with check digits are filled in from generators at build time (`eval/build_testset.py`).
* **Detection metrics** (`eval/evaluate.py`): *exact* = same span and type; *overlap* = same type, spans overlap; *protected* = ≥95% of the entity's characters covered by any predicted span regardless of type (what matters for privacy). Wilson 95% intervals. Each backend runs in its own process; memory is RSS.
* **Restoration** (`eval/restore_eval.py`): every name is masked in each of the 12 cases of its gold inflection table (persons and companies use different case sets), then a simulated model mentions it again in a random case from the same table with a perturbation real models produce (missing brackets, glued or en-dash endings, lower case, markdown, first-name-only or *X úr* mentions, upper case). The expected text comes from gold inflection tables (`eval/data/inflection_gold*.json`) written by two independent AI annotators (dev: plus an AI adjudicator), never from the engine under test.
* **Not measured:** real LLM behaviour, real documents, human-verified labels, multi-turn conversations, English-language detection quality.
